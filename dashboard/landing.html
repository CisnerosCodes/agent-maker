How it works

One goal in. A whole org out.

Type make me a shopify store. The CEO asks one clarifying question, drafts the org, and the Factory brings each hire to life — you watch it happen on a live org chart.

01

You give the goal

Plain language, in the dashboard or from your own AI over MCP. The CEO interviews you once and remembers your business.

02

The CEO drafts the org

Goal becomes roles, hired from a real role library: research, store-builder, copywriter, strategist, analyst. Builders wait on research.

03

The Factory births workers

Each worker gets a scoped identity, an OpenShell policy, and a NemoClaw sandbox — identity, then policy, then sandbox, visible in the event log.

04

You stay in command

An autonomy dial — assisted, supervised, autonomous — plus approve or deny on plans and security escalations.

Runtime security

Security is the product, not a checkbox.

Every model input, output, tool call, and ingested document passes through the SecurityGate — HiddenLayer Runtime Security. Detections route by policy: log, block, or escalate to a human. And when the gate says no, the sandbox agrees: defense in depth means the OpenShell egress policy blocks the exfil host independently.

Recursive intelligence

The company gets faster every run.

Run memory

It remembers work it has done

Every completed goal is written to memory. Launch the same niche twice: run two recalls run one, reuses its findings — zero re-scrapes, zero research calls — and the dashboard shows the run-over-run speedup.

Eval ladder

Workers are benchmarked before hired

A 20-level instruction-following ladder finds the exact point a model breaks under pressure. If a backend and model clear the ladder, that exact pair runs the workers. See live results

Role library

New roles are entries, not code

The CEO hires from a role library — store-launch, marketing-agency, market-research playbooks. Extending the company means adding a library entry, not touching the orchestrator.

Honest by design. Every agent is labeled REAL or SIM — live scrapes, real API calls, and mock sources are never confused. Judges included.
