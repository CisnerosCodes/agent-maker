Capabilities

From vision to shipped.

I want to sell 3D horror assets on the Unity store.
  1. The CEO interviews you — narrows the goal to Unity Asset Store, horror packs, a price band.
  2. research-1 sweeps the catalog for AI asset tooling. verdict: nothing fits
  3. The decision lands on your desk: no tool exists — should the colony build one? You: yes.
  4. toolsmith-1 is hired to build an asset-maker — an MCP tool, written and run in its own sandbox.
  5. maker-1 generates the packs with it · qa-1 validates every mesh, rejects three, regenerates.
  6. store-1 preps listings, descriptions, screenshots. You get assetstore.unity.com/publishers/you — and you did nothing but answer questions.
I sell shoes at markets. Photos I have — time I don't.
  1. The CEO interviews her — local sales, no web presence. She needs a store and a way to be found.
  2. research-1 ranks her channels: own storefront + social beats marketplaces on margin.
  3. webmaster-1 builds the storefront · connector-1 wires Shopify, Stripe, and the deploy.
  4. She drops product photos in the channel. That's her whole job.
  5. listing-1 turns each photo into a titled, described, priced listing — straight onto the store.
  6. Store live, launch posts scheduled. maya-kicks.myshopify.com lands in her inbox.
How it stays this flexible: every integration is an entry in a capability catalog — commercepaymentsmediaresearchdeployoutreach — that the CEO searches when it drafts an org. A capability that's missing becomes either a question to you or a tool the colony builds itself. New APIs are new catalog entries, not new orchestrator code.

FAQ

Curious about the colony?

Straight answers about autonomy, security, and what's real versus simulated.

Is the security real or a demo?

Real. Every message and worker I/O passes a security gate — HiddenLayer runtime scanning with a heuristic floor that's always on. Deny an escalation and the sandbox egress policy blocks the exfil host independently.

Do agents act without my approval?

Only as far as you allow. The autonomy dial has three settings — assisted, supervised, autonomous. In supervised mode (the default) every org plan and every security escalation stops and waits for your approve or deny.

Which models run the workers?

Whichever brains clear the 20-level instruction-following ladder — Claude and NVIDIA Nemotron out of the box. If a backend and model pair clears the ladder, that exact pair runs your workers; if it breaks, it's never hired.

Can my own AI drive the colony?

Yes. Connect any MCP client and say "set up my agent company" — it onboards you, launches goals, watches the org live, and explains every escalation. claude mcp add clawcolony -- npx tsx src/mcp/server.ts

What's real and what's simulated?

Every agent is labeled REAL or SIM in Mission Control — live scrapes, real API calls, and mock sources are never confused. Connect a key and the tag flips from SIM to REAL. Judges included.
